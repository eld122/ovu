First launch

Ovu isn’t signed with a paid developer certificate, so your system asks for one extra confirmation.

Mac says the app is damaged

Move Ovu to Applications, then run this once in Terminal:

xattr -cr /Applications/Ovu.app
Windows shows “Unknown publisher”

Select More info, then Run anyway.

Linux AppImage won’t start

Make it executable, then open it:

chmod +x Ovu-*.AppImage && ./Ovu-*.AppImage

in Ubuntu 24+:

./Ovu-*.AppImage --no-sandbox
Android blocks the install

Open the .apk, then allow “Install unknown apps” for your browser or file manager.

Questions

Is Ovu really free?

Yes. Every download is free, with no trial and no account.

Does it work offline?

Yes. Drawing, layers, skies, history and export all work without a connection. Live collaboration and the marketplace need the optional Ovu server.

Where are my projects stored?

On your own device. Export a project file or a .glb whenever you want a copy.

Can I use it on a tablet or phone?

On Android, yes — install the .apk. Touch drawing works, and exports open in your share sheet.

Why isn’t it in an app store?

Store listings need paid developer accounts. Ovu is distributed directly so it can stay free.
